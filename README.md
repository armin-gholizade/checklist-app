# لیست من

برنامهٔ محلی فارسی با Angular 21، NestJS، Prisma 6 و PostgreSQL.

**اگر نسخهٔ قبلی را دارید، ابتدا UPDATE.md را بخوانید.**

## نصب اولیه

پیش‌نیازها: Node.js 24، npm و Docker Desktop. ترمینال را در پوشهٔ حاوی package.json باز کنید:

```powershell
npm ci
node scripts/setup.mjs
docker compose up -d --wait
npm run db:generate
npm run db:migrate
npm run dev
```

http://localhost:4200 را باز کنید. «ایجاد حساب کاربری» را بزنید. نام کاربری ۳ تا ۴۰ حرف انگلیسی، عدد، نقطه، خط تیره یا زیرخط و رمز ۸ تا ۱۲۸ کاراکتر است.

برای دفعات بعد فقط Docker Desktop، `docker compose up -d --wait` و `npm run dev` لازم است.
فرانت‌اند تغییرات را بارگذاری می‌کند؛ برای تغییرات بک‌اند dev را دوباره اجرا کنید.

## قابلیت‌ها

- ورود، ثبت‌نام، خروج و جداسازی داده‌های کاربران
- ساخت/ویرایش لیست با توضیحات، حذف با Undo، آرشیو/بازگردانی
- عنوان، یادداشت، اولویت، موعد انجام و تیک آیتم
- ویرایش سریع عنوان، جست‌وجو و فیلتر وضعیت
- ترتیب دستی با Angular CDK Drag & Drop یا دکمه‌های جابه‌جایی
- رابط فارسی، موبایل، کنترل صفحه‌کلید و فونت محلی

تاریخ ورودی میلادی است و به فارسی نمایش داده می‌شود. اعلان زمان‌بندی‌شده وجود ندارد. Undo با بستن اعلان، refresh یا خروج از حساب از رابط حذف می‌شود؛ دادهٔ soft-delete همچنان در دیتابیس باقی می‌ماند. آیتم‌های لیست آرشیوشده فقط خواندنی‌اند.

## توسعه و آزمون

```powershell
npm run build
node --test tests/security.test.cjs
```

برای تست API روی یک محیط تست جدا (دو حساب آزمایشی ایجاد می‌کند):

```powershell
$env:TEST_API_URL="http://127.0.0.1:3000/api"
node tests/api.integration.mjs
```

ساختار و قواعد توسعه در ARCHITECTURE.md و نتیجهٔ بررسی در VERIFICATION.md آمده است.

## تنظیمات

فایل apps/api/.env از نمونه ساخته می‌شود. JWT_SECRET تصادفی است. اگر PostgreSQL خودتان را دارید، DATABASE_URL را تغییر دهید و مرحلهٔ Docker را رد کنید. دیتابیس Docker روی 127.0.0.1:5432، API روی 127.0.0.1:3000 و Angular روی 127.0.0.1:4200 است؛ `/api` از proxy توسعه عبور می‌کند.

توقف دیتابیس بدون حذف داده: `docker compose down`.

این پروژه برای استفادهٔ محلی است. برای انتشار، تنظیمات HTTPS، cookie امن، secretها و وب‌سرور production باید جداگانه آماده شود.

## انواع لیست

| نوع | فیلدهای آیتم |
|---|---|
| کارها | عنوان، تیک، یادداشت، اولویت، موعد انجام |
| خرید | عنوان، تیک، تعداد/مقدار، واحد، قیمت تخمینی هر واحد |
| ساده | فقط عنوان و تیک |

نوع لیست هنگام ساخت انتخاب می‌شود و ثابت می‌ماند. افزودن سریع خرید، «۱ عدد» با قیمت نامشخص می‌سازد؛ از «ویرایش خرید» مقدار و قیمت را تغییر دهید. ترتیب، جست‌وجو، آرشیو و Undo برای هر سه نوع فعال‌اند.

تست اختصاصی انواع لیست روی API تست جدا:

```powershell
$env:TEST_API_URL="http://127.0.0.1:3000/api"
node tests/list-types.integration.mjs
```
